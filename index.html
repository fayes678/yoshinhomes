Latihan soal

Skor: 0 / 0

Kenapa jumlah host dikurangi 2?

Dari semua alamat dalam satu subnet, alamat pertama dipakai sebagai alamat network (nama subnet itu sendiri) dan alamat terakhir sebagai broadcast (alamat untuk menyapa semua host). Keduanya tidak boleh dipasang ke perangkat. Contoh /24: 256 alamat, 254 untuk host.

Apa beda netmask dan wildcard?

Wildcard adalah kebalikan netmask: bit 0 artinya harus sama, bit 1 artinya boleh beda. Netmask dipakai di konfigurasi IP biasa, wildcard dipakai di ACL Cisco dan OSPF. Rumus cepat: wildcard = 255.255.255.255 dikurangi netmask.

Kapan pakai /30, /31, dan /32?

/30 (2 host) lazim untuk link antar router. /31 (2 alamat, tanpa network dan broadcast) dipakai untuk link point-to-point modern. /32 satu alamat saja, dipakai untuk loopback atau rute host.

Bagaimana memilih prefix dari jumlah host?

Cari pangkat 2 terkecil yang lebih besar atau sama dengan host + 2. Butuh 50 host: 50 + 2 = 52, pangkat 2 terdekat 64 = 2^6, jadi bit host 6 dan prefix = 32 − 6 = /26 (62 host).

Rentang alamat private apa saja?

10.0.0.0/8, 172.16.0.0 sampai 172.31.255.255 (/12), dan 192.168.0.0/16. Alamat ini tidak diroute di internet, jadi butuh NAT untuk keluar. 100.64.0.0/10 adalah CGNAT milik ISP.

Kelas A/B/C masih dipakai?

Kelas (A /8, B /16, C /24) adalah sistem lama. Sekarang yang dipakai CIDR, prefix bebas dari /0 sampai /32. Kelas hanya dipakai sebagai tebakan prefix kalau kamu mengetik IP tanpa prefix.

    Cara hitungnya
    Beban puncak = CPU (TDP dikali 1,15; 1,3 kalau overclock) + GPU (TBP; dikali 1,15 kalau overclock) + 40 W motherboard + 5 W per keping RAM + 8 W per drive + 3 W per fan. CPU modern sering menarik daya di atas TDP saat boost, itu alasan pengali 1,15.
    
              
    Kenapa PSU tidak dibuat pas-pasan?
    PSU paling efisien dan paling adem di sekitar 40 sampai 70% bebannya, dan komponennya menua sehingga kapasitas efektif turun. Rekomendasi di sini membuat beban puncak sekitar 75% kapasitas atau lebih longgar, lalu dibulatkan ke ukuran yang ada di pasaran.
    
              
    Apa itu lonjakan (transient) GPU?
    GPU kelas atas bisa melonjak sesaat jauh di atas TBP-nya dalam hitungan milidetik. PSU murah bisa mati mendadak karena proteksi (OCP). Karena itu perhitungan juga memastikan ada cadangan minimal 40% dari TBP GPU di atas beban puncak.
    
              
    Arti 80 Plus Bronze, Gold, Platinum
    Itu rating efisiensi konversi AC ke DC. Makin tinggi, makin sedikit daya terbuang jadi panas dan makin hemat listrik, biasanya dengan kualitas komponen internal yang lebih baik. Untuk PC di bawah 400 W Bronze sudah cukup, 400 sampai 800 W pilih Gold, di atas itu Platinum. Merek dan reviu tetap lebih penting daripada sekadar stiker.
    
              
    Biaya listrik dihitung dari apa?
    Rata-rata daya = beban puncak dikali faktor pemakaian (kantor 35%, gaming 70%, kreator 85%), dikali jam per hari, 30 hari, dan tarif. Isi tarif sesuai tagihanmu. Angkanya perkiraan, bukan hasil pengukuran.
    
              
    Tentang katalog dan simpan build
    Daftar CPU dan GPU berisi TDP/TBP resmi (perkiraan) dan dikelola admin. Masuk ke akunmu untuk menyimpan sampai 20 build dan memuatnya lagi kapan saja.
